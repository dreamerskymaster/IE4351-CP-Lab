VLAB Access – OCTOPUZ

Virtual Lab Setup for Robot Programming

💻🌐

OCTOPUZ software is available via the COE Virtual Lab (VLAB). This allows you to program robots from any device, anywhere.

📝 Overview:
This guide walks you through account registration, VPN connection, and client installation needed to access the virtual desktop.
🏠 Hub

🔑 Step 1: COE Account

Register for Engineering Services

1
Request an Account:
Visit the COE/ECE Computer Account page and click "Request an account."
⚠️ Network Restriction:
The registration form requires you to be on the NUwave campus network or connected to the NU VPN. If you are off-campus, complete Step 2 (VPN) first.

🌐 Step 2: NU VPN

Access the Campus Network from Home

Required only if you are working off-campus.

A
2FA Enrollment: Ensure you are enrolled in NU 2FA.
B
Client: Download GlobalProtect at vpn.northeastern.edu.
C
Login: Sign in with your standard NU Credentials (not COE).

🖥️ Step 3: Horizon Client

Installing the Omnissa Connection Tool

The Horizon Client provides a better experience than the web browser version.

🔓 Step 4: Login & Select VM

Accessing the Windows Environment

1
Credentials: Sign into the client using your COE Username and COE Password (the ones you requested in Step 1).
2
Pool Selection: Once logged in, double-click the "COE Windows 11" icon.
💡 Note:
The first time you log in, it may take 1-2 minutes to prepare your virtual desktop profile.

🤖 Step 5: Find OCTOPUZ

Start Programming

Inside the virtual desktop:

  1. Click the Start Menu (Windows Icon).
  2. Click All Apps.
  3. Scroll to OCTOPUZ and select it.
  4. Open the IE 4531 folder for course assets.
🚀

Setup Complete!

You are now ready for the Offline Robot Programming Lab.
