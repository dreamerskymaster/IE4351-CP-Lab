Software Access

Access OCTOPUZ via the COE Virtual Lab

The offline robot programming software OCTOPUZ is available on the College of Engineering's Virtual Lab (VLAB), a virtual computer you can use from anywhere.

Setup Steps
1
Register for a COE account
Visit the COE/ECE Computer Account page and click "Request an account."
Note: The registration form requires you to be on campus or connected to the NU VPN. If you are off-campus and do not yet have a COE account, complete Step 2 first using your NU credentials, then return here.
2
Connect to the NU VPN (if off-campus)
If you're not on the NUwave network, set up the NU VPN first.
Download the VPN client at vpn.northeastern.edu and sign in with your NU credentials (not COE credentials).
Note: You must be enrolled in NU Two-Factor Authentication (2FA) before you can access the VPN download page.
3
Install Omnissa Horizon Client
Download and install the approved version for your operating system. Once installed, add omnissaconnect.coe.neu.edu as a new server.

Log in & select the virtual machine
Sign in with your COE credentials and click "COE Windows 11".
5
Find OCTOPUZ
Inside the virtual desktop, go to Start → All Apps. You should find OCTOPUZ listed there.
Tip: The VPN (Step 2) is only needed if you're off campus. If you're connected to NUwave on campus, you can skip straight to Step 3.
